# Laboratório Azure Speech Studio e Language Studio

## Objetivo

Este projeto foi desenvolvido como parte do desafio da DIO, com o objetivo de praticar e aprofundar o conhecimento sobre ferramentas de Inteligência Artificial do Microsoft Azure voltadas para processamento de fala e linguagem natural.

Durante este laboratório foram explorados recursos do **Azure Speech Studio** e **Azure Language Studio**, com foco em reconhecimento de voz, conversão de fala em texto e análise de informações textuais utilizando Inteligência Artificial.

---

# Tecnologias utilizadas

* Microsoft Azure
* Azure Speech Studio
* Azure Language Studio
* GitHub
* Markdown

---

# Etapa 1 - Criação do recurso Azure Speech

Nesta etapa foi realizada a criação de um recurso de Inteligência Artificial no portal Microsoft Azure para utilização dos serviços de fala.

## Configurações do recurso

**Serviço criado:** Azure Speech Services
**Nome do recurso:** speech-dio-rubia
**Grupo de recursos:** rg-speech-dio
**Região utilizada:** South Central US
**Camada:** Free F0

Durante a criação do recurso foi necessário considerar as limitações da assinatura **Azure for Students**, selecionando uma região disponível para implantação do serviço.

# Etapa 2 - Azure Speech Studio

Nesta etapa foi utilizado o Azure Speech Studio para explorar recursos relacionados ao processamento de voz.

## Atividades realizadas

* Acesso ao ambiente Speech Studio;
* Configuração do recurso criado no Azure;
* Exploração das funcionalidades disponíveis;
* Teste utilizando conversão de fala em texto (**Speech to Text**).

## Resultado obtido

O Azure Speech Studio demonstrou a capacidade de transformar áudio em texto utilizando modelos de Inteligência Artificial para reconhecimento automático de voz.

Essa tecnologia pode ser aplicada em diversos cenários, como:

* Transcrição automática de reuniões;
* Criação de legendas;
* Assistentes virtuais;
* Soluções de atendimento ao cliente.

# Etapa 3 - Azure Language Studio

Nesta etapa foi explorado o Azure Language Studio, uma ferramenta voltada para processamento de linguagem natural (**Natural Language Processing - NLP**).

O Language Studio permite analisar textos utilizando modelos de Inteligência Artificial capazes de identificar informações, padrões e sentimentos presentes em conteúdos textuais.

## Funcionalidades exploradas

* Análise de sentimentos;
* Classificação de textos;
* Identificação de informações relevantes;
* Processamento de linguagem natural.

## Aplicações práticas

Os recursos do Azure Language Studio podem ser utilizados em soluções como:

* Análise de opiniões de clientes;
* Classificação automática de mensagens;
* Chatbots inteligentes;
* Automação de atendimento.
